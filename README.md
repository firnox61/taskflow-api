# TaskFlow API

TaskFlow, bir yazılım ekibinin görevlerini yönetmek için geliştirilmiş REST API projesidir. API; görev oluşturma, görevleri listeleme, görev detayını görüntüleme, güncelleme ve silme işlemlerini destekler.

## Gereksinimler

- Node.js
- npm

## Kurulum

Proje klasöründe terminal açıp bağımlılıkları yükleyin:

```bash
npm install
